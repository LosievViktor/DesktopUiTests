# DesktopUiTests

C# code examples for Desktop UI automation tests made with FlaUI library.

Stack : C#, FlaUI, NUnit;

For target application, I've took https://github.com/LosievViktor/MauiUkraine application

C# example of MAUI application with Ukrainian language user interface . 

1. Clone and build https://github.com/LosievViktor/MauiUkraine
2. In AppConfig.cs set path to exe file of MAUIUkraine application
3. Build  solution and launch tests.
